# Artificial-Intelligence-by-Personifwy
This repository is a collection of mini-projects and projects performed during the course and 2-month internship.
The projects focus on using python scripts for applying machine learning and AI.

## Mini-projects

- **Object recognition (`obj_recognition.ipynb`)** — Trains a convolutional neural network on CIFAR-10 to classify images into categories such as cars, animals, and airplanes.
- **Fake news classification (`news-classification (2).ipynb`)** — Uses text preprocessing and TF-IDF features with machine-learning classifiers to distinguish fake news from genuine news.
- **Fashion MNIST classification (`Fashion_MNIST_Classification.ipynb`)** — Builds a convolutional neural network to classify grayscale clothing images into 10 fashion categories.
- **Handwritten digit classification (`CNN_classification.ipynb`)** — Trains a convolutional neural network on MNIST to recognize handwritten digits from 0 to 9.
